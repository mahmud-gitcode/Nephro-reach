# Architecture decision records

One file per decision that cost something to make, so it does not get
re-argued from scratch — or quietly reversed by someone who never saw the
reasoning.

Each one says what was decided, what it rules out, and what would make it
worth revisiting. A decision with no revisit condition is a decision nobody
can ever change.
